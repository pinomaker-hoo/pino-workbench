# Pino Workbench identity

- `icon.png`: original 1280×1280 PNG with alpha, used for the desktop window, application bundle and repository branding.
- Concept: three sage-green pine chevrons suggest connected layers of work; the dark forest tile keeps the mark legible as an app icon.
- Created with OpenAI image generation for this project. Included under this repository's MIT license.
- Colors used in the application: charcoal `#121915`, sage `#B1CD90`, pale text `#DEE6D8`.

Noto Sans KR Regular and Bold are embedded for reliable Korean text rendering. The font files are from [notofonts/noto-cjk](https://github.com/notofonts/noto-cjk/tree/main/Sans/SubsetOTF/KR), redistributed under the SIL Open Font License in `FONT-LICENSE.txt`. The font license is separate from the application MIT license.
